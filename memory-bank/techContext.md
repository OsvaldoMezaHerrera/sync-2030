# Tech Context

- **Sistema Operativo:** Fedora Linux 44 (Node.js v22, npm, Zsh).
- **Stack Frontend:** React + Vite + Tailwind CSS + Lucide React (iconos).
- **Persistencia:** Estado en React sincronizado con `localStorage` + archivo de datos semilla (`src/data/seedData.js`) con botón visible de **"Reiniciar datos demo"** (clave para ensayar y presentar el pitch limpio).
- **Modo Offline Garantizado:** Toda la lógica del Gemelo de Sincronía, traductor de tono, candado de no-compromiso y las 7 pruebas funciona 100% en local sin internet (con opción en ajustes para conectar API compatible con OpenAI / LiteLLM si se desea).
- **Comandos:** `npm install`, `npm run dev`, `npm run build`.
